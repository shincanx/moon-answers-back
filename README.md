An entry for make.fun's [The Moon Finally Answers Back](https://make.fun/bounty/u-mang-the-moon-finally-answers-back-781a7ec1) bounty ($2, top places share the pool).

`main.py` writes one line of text — the Moon's answer to everyone who has ever stared up at it — capped at 240 characters, to `entry.txt` in the output directory. Deterministic, no network, no randomness. The line is the whole entry.

> I heard every wish, every howl, every 2 a.m. promise. I'm a rock — I don't do refunds, I do tides.

98 characters, within the 240-character cap. The Moon proves it was listening all along, then undercuts four billion years of reverence with the flattest job description possible: a rock. The comeback lands in the last clause — no refunds, only tides, the one thing the Moon actually delivers.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
